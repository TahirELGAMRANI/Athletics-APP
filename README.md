# AUI Athletics

Internal operations app for the **Al Akhawayn University Athletics Department**.

**Web:** https://aui-athletics.vercel.app · **Publishing to the App Store / Google Play:** see [RELEASE.md](RELEASE.md)
 It runs on iOS, Android and the web from one Expo (React Native) codebase, with a Supabase backend (Postgres, Auth, Storage, Edge Functions).

## Run locally

```bash
npm install
npx expo start          # press w for web, or scan the QR code with Expo Go (iOS/Android)
npm run build:web       # static web build in dist/ (what Vercel deploys)
npm run typecheck
```

The Supabase URL and publishable key default to the production project (`src/lib/supabase.ts`); override with `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_KEY`.

### On an iPhone

* **Fastest (no install):** open the web link in Safari → Share → **Add to Home Screen**. It opens full-screen like a native app.
* **Native app via Expo Go:** install *Expo Go* from the App Store, run `npx expo start --tunnel` on a computer, and scan the QR code with the iPhone camera.
* **Always-on link without a computer:** `npx eas-cli@latest login` (free Expo account) then `npx eas-cli@latest update --branch preview`; open the printed link in Expo Go.

## Database

SQL lives in `supabase/`:

* `migrations/0001_schema.sql` – tables, row-level security, booking rules, storage bucket
* `migrations/0002_seed_reference.sql` – facilities, teams, official programs, volleyball roster, 1st physical test results, first attendance session (generated by `scripts/gen_seed.py`)
* `migrations/0003_harden_functions.sql` – security advisor fixes
* `migrations/0004_womens_futsal_roster.sql` – women's futsal roster
* `migrations/0005_flexible_physical_tests.sql` – flexible test format (any tests/trials/scoring) + women's futsal Day 1 & Day 2 results (generated by `scripts/gen_futsal.py`)
* `seed/test_accounts.sql` – the test accounts above
* `functions/admin-create-user` – Edge Function super admins use to create accounts
* `functions/delete-account` – Edge Function behind Profile → Delete my account (required by the App Store)
